# 道德经描字帖 · daodejing-miaozitie

一个**纯描红 / 书法练习**的单文件网页，把《道德经》81 章的经典句变成可以一笔一画描写的字帖。

## 特点
- **81 章全覆盖**：按王弼通行本分章，每章精选句逐字描红。
- **金骨架描红**：汉字以开源笔画数据（Arphic PL）生成的金色骨架呈现，**零字体依赖、跨端一致、无字体侵权**。
- **朱砂莲花插图**：81 章插图以水墨风格绘制。
- **离线单文件**：打开 `index.html` 即玩，无需联网、无需安装。

## 附带经文原文
仓库另附两份《道德经》纯经文 markdown，便于离线阅读与检索：
- `道德经.md` —— 王弼通行本（81 章，无拼音）
- `道德经-帛书版.md` —— 马王堆帛书版（甲本特征：恒 / 弗 / 也）

经文约 2500 年前成书，属公有领域；本整理由 橙橙 完成，采用 CC BY-NC-SA 4.0，仅供非商业学习交流。

## 使用
直接用浏览器打开 `index.html` 即可（手机 / 平板 / 电脑均可，支持触屏手写描红）。

## 定位说明
本项目定位为**国学书法描红 / 古典汉字练习**工具，不侧重义理讲解，聚焦笔顺描摹与心手合一。
